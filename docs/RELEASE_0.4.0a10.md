# BaSIS AWARE 0.4.0a10

The screening report links findings to their retained DeepSafe outcomes, including deferred and unresolved reviews. A paginated print view keeps large screening tables usable.

Researchers can prepare and verify versioned, offline reference collections with source citations and file checksums. An optional DOI lookup creates a pending citation for researcher review. See [the catalog guide](REFERENCE_CATALOG.md) for the file format and workflow.
